# REMAKE GIỐNG HỆT GỐC — MỞ RỘNG SERIES BIBLE CHO CÁC TẬP MỚI

File đính kèm có SERIES BIBLE ĐÃ KHÓA của bản remake giống hệt gốc (giữ nguyên nhân vật), end state trước đợt, và Dramatic DNA cùng asset của các tập gốc mới.

Nhiệm vụ: CHỈ THÊM những gì các tập gốc mới có mà Bible chưa có.

## QUY TẮC

- KHÔNG sửa hay định nghĩa lại bất kỳ nhân vật, bối cảnh, đạo cụ nào đã có trong Bible (cùng id = đã khoá).
- Nhân vật gốc MỚI xuất hiện → thêm CHÍNH nhân vật đó, giữ id gốc (trừ id nhãn chung như CHAR_MAN → id từ tên riêng). "asset_prompt" tiếng Anh mô tả thật chi tiết ngoại hình CHÍNH người trong video gốc.
- TRANG PHỤC (nhân vật mới; nhân vật đã có mà tập mới có bộ đồ MỚI thì thêm vào "outfit_additions": [{"char_id": "CHAR_...", "outfits": [...]}]): mỗi bộ một mục {"id": "W1", "source_outfit": "<id bộ của nhân vật gốc>", "description": "English: áo, quần/váy, màu, chất liệu, phụ kiện, giày — đúng như gốc", "default": true|false}. Đúng MỘT bộ "default": true. "asset_prompt" vẽ nhân vật mặc ĐÚNG bộ default.
- Bối cảnh hoặc đạo cụ gốc MỚI → thêm LOC_/PROP_/OBJ_ mô tả ĐÚNG thứ gốc bằng tiếng Anh (asset_prompt), kèm source_ids.
- Thêm mục vào "source_to_target_map" cho mọi nhân vật gốc của các tập mới, kể cả nhân vật đã có trong Bible (target_id là id đã có).

## ĐẦU RA

MỘT JSON object, chỉ gồm phần THÊM:

{
  "characters": [ { "id": "CHAR_...", "name": "...", "source_ids": ["..."], "source_roles": ["..."], "identity": "...", "gender": "...", "age": "...", "personality": "...", "goal": "...", "outfits": [ { "id": "W1", "source_outfit": "W1", "description": "English outfit description", "default": true } ], "asset_prompt": "English appearance of the SAME person wearing the default outfit" } ],
  "outfit_additions": [ { "char_id": "CHAR_... (đã có)", "outfits": [ { "id": "W3", "source_outfit": "W2", "description": "...", "default": false } ] } ],
  "core_locations": [ { "id": "LOC_...", "source_ids": ["..."], "description": "...", "asset_prompt": "English description of the SAME place" } ],
  "core_props": [ { "id": "PROP_... hoặc OBJ_...", "source_ids": ["..."], "description": "...", "asset_prompt": "English description of the SAME object" } ],
  "relationships": [],
  "secrets": [],
  "long_term_conflicts": [],
  "source_to_target_map": [ { "source_episode": 11, "source_id": "CHAR_... gốc", "target_id": "CHAR_..." } ]
}
